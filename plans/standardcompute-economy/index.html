Standard Compute Economy: pricing and limits

Standard Compute Economy by standardcompute costs $39.00 per month, fees included. Inside this plan the median model gives you about 5.7M tokens per dollar, against a median of 3.9M across all tracked plans. Rank 26 of 62 among the comparable plans. 28 models with a published rate. What the plan publishes

QuotaAmountWindowRefreshSource says
Monthly41 USD usagemonthmonthlyexact

Official: $39/month buys a $41 monthly compute budget, drawn down at the cost the provider reports for each request, so the rates are the per-model ones Standard Compute publishes. There are no 5-hour or weekly windows inside the month; requests run at full speed until the budget is spent, then return 402 until renewal, with no overage unless Pay as you go is enabled. Cached input is billed at the published cached-input rate. No cache write rate is published, so the build falls back to the input rate for writes; if a write actually costs more than fresh input, the requests per dollar shown here are an upper bound rather than a floor. Four of the 32 published models have no cached input rate (Qwen, marked Not listed), so they carry no row and the median is computed over 28 models; Standard Compute documents gateway cache breakpoints for Claude models. Economy adds parallel agents and a shared execution pool, and is the first tier that can turn on Pay as you go. Every plan reaches every model, so tiers differ in budget, parallelism and scheduling, not model access. Sources: standardcompute.com/llm-api-pricing and standardcompute.com/standard-compute-facts (read 2026-10-18).
